41. Datetime-Formatted Strings for Filenames

Timestamp conventions that sort correctly, parse unambiguously, and work across OS/tools.

Core tension: ISO 8601 (2026-08-11T14:30:22Z) is the standard but contains colons (illegal in Windows filenames) and T separators that hurt readability. Need a filename-safe variant that preserves sort order and parseability.

Proposed Convention

Use CaseFormatExample

Pipeline runsYYYYMMDD-HHmmssrun-20260811-143022.log
Sub-second batchesYYYYMMDD-HHmmss-SSSbatch-20260811-143022-817.parquet

Rules

1. No colons, no T, no + in filenames — these break on Windows/URLs.

2. All timestamps UTC unless explicitly local (suffix -local if needed).

3. Compact form (no hyphens in date) for embedded timestamps; expanded for human-facing.

4. Timestamp goes after the semantic name, before extension: name-timestamp.ext.
