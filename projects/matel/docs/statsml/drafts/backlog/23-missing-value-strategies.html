Missing Value Strategies by Scenario

TO DISCUSS

How should the pipeline handle missing values depending on why they're missing, what kind of feature it is, and what downstream task is intended?

Core Scenarios to Cover

Missingness Mechanism
  • MCAR — missing completely at random (safe to drop/impute simply)
  • MAR — missing depends on observed variables (conditional imputation needed)
  • MNAR — missing depends on the unobserved value itself (dangerous — imputation biases results)
How do we detect which mechanism is at play? What heuristics/tests can the pipeline run automatically?
Feature Type Matters
  • Continuous — mean/median/KNN/regression imputation; distribution-aware choices
  • Categorical — mode, "Unknown" category, or model-based
  • Binary — is missing itself informative? (missingness-as-feature)
  • Ordinal — interpolation vs category-based
Should imputation strategy be tied to the detected feature type from our type classifier?
Missingness Patterns
  • Sparse random — scattered, low % → simple imputation likely fine
  • Block missing — entire columns/rows absent for a subpopulation
  • Monotone — dropout pattern (later variables more missing)
  • Structured — missing because logically not applicable (e.g., "spouse income" for single people)
Structured missingness is NOT a data quality issue — it's domain semantics. How does the pipeline distinguish this from broken data?
Downstream Task Dependency
  • Descriptive stats — complete-case analysis may suffice if MCAR
  • Hypothesis testing — missing data can destroy power or bias p-values
  • ML prediction — some models handle NA natively (tree-based); others cannot
  • Causal inference — MNAR missingness can create spurious associations
Should the pipeline recommend different strategies based on what test/model is planned?

Key Discussion Points

  • When is "drop rows" acceptable vs dangerous? (threshold: 5%? depends on N? depends on pattern?)
  • When should missingness itself become a binary feature?
  • Multiple imputation vs single imputation — when does it matter?
  • How does this interact with our existing 02-value-existence-mapping work?
  • Domain-specific conventions (e.g., healthcare: missing lab = not ordered ≠ normal result)
  • Should the pipeline ever refuse to proceed if missingness is too high or clearly MNAR?
