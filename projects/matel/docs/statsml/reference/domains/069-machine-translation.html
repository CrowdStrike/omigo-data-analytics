Machine Translation

Critical pitfalls in neural machine translation systems and evaluation

Pitfall Description
BLEU score ≠ quality BLEU measures n-gram overlap with reference; a perfectly natural translation using different words scores 0; high BLEU possible with unnatural but reference-matching output
Low-resource language data desert 80% of training data is English/Chinese/European; 7000 languages exist; most have near-zero parallel corpus; "universal" translation = works for 20 languages, fails for 6980
Domain terminology drift Medical "culture" = lab culture; legal "party" = litigant; financial "interest" = rate; general model mistranslates domain terms catastrophically; one wrong word in legal = liability
Gender/formality ambiguity English "you" → formal/informal in 50+ languages; English "they" → gendered pronoun required in target; model must GUESS information not present in source; systematic bias toward masculine default
Context window insufficient Pronoun in paragraph 3 refers to noun in paragraph 1; model translates sentence-by-sentence → loses document coherence; "it" becomes wrong gender because antecedent is outside window
Meaning preservation unmeasurable Can you prove translation preserves meaning? Only a bilingual human can verify; at 1M translations/day no human can check; quality is fundamentally unverifiable at scale
