Mobile Security Pitfalls

1. App Store Review ≠ Safe
App passes initial review → pushes malicious update 2 weeks later → review of updates is less rigorous. "It's on the App Store" creates a false sense of security. Malware is frequently introduced AFTER initial approval, exploiting the trust users place in store-reviewed apps. The initial gate does not guarantee ongoing safety.
2. On-Device vs Cloud Detection Tradeoff
On-device detection: low latency but limited compute and model size. Cloud detection: powerful but requires network connectivity and raises privacy concerns when sending user data. Neither alone is sufficient. Both have coverage gaps — on-device misses complex threats, cloud misses offline attacks. The gap between them is where threats hide.
3. Jailbreak/Root Detection Cat-and-Mouse
App checks for jailbreak → attacker hides jailbreak from detection → app adds new check → attacker patches that check. An endless cycle where detection is always one step behind. You cannot trust the device's self-report because the compromised OS controls what the app can observe.
4. Permission Creep Invisible to User
App requests camera on install → user grants → forgets → app uses camera in background 6 months later. Permission was granted but context has changed. Static permissions do not equal real-time appropriate access. The user's mental model of what they allowed diverges from actual app behavior over time.
5. Sideloading Bypasses All Controls
Android APKs installed outside Play Store: enterprise apps, regional apps, pirated apps. No store review, no safety scanning, no update mechanism. Completely unmanaged software running with full permissions. Sideloading creates a parallel universe of apps with zero guardrails that coexist with vetted apps on the same device.
6. Network Switching Disrupts Monitoring
Phone switches WiFi → cellular → different WiFi → VPN → cellular. Each switch means a different IP, different routing, different visibility. Continuous monitoring of a device that constantly changes its network identity is extremely hard. The device is the same but its network fingerprint is constantly shifting.
