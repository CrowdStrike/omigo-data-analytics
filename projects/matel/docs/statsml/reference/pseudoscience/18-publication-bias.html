Publication Bias / File Drawer Effect

Structural — Only Positive Results Get Published, Creating Systematically Distorted Literature

Only Positive Results Get Published — Creating a Systematically Distorted Literature
  • Pharma: 10 studies run on Drug X. 8 show no effect. 2 show positive effect. Published: the 2 positive. Result: "the literature shows Drug X works!" The 8 negative studies sit in file drawers. The published record is a BIASED SAMPLE of all evidence. Meta-analysis of published studies inherits this distortion.
  • Psychology: Priming effects, power poses, ego depletion — all "established" by positive publications. Replications (negative results) couldn't get published for years. Entire subfields built on the SURVIVING positive results while negative evidence was suppressed. This isn't a conspiracy — it's incentive alignment (journals want novel positive results).
  • Internal company data: A/B tests that show "no effect" are never presented to leadership. Tests that show improvements get full presentations. Result: leadership believes "everything we try works!" because they only see the positive outcomes. The negative experiments are invisible.
  • ML papers: "Our method beats all baselines!" You never see papers saying "we tried 50 architectures and none beat logistic regression." Those papers don't get accepted. The literature makes it LOOK like progress is constant, when really most things fail silently.

Why it's pseudoscience: The evidence base is systematically filtered to over-represent positive results. Any conclusion drawn from this filtered evidence is biased upward. You're not reading "what's true" — you're reading "what was publishable." The file drawer contains the TRUE base rate of failure.
