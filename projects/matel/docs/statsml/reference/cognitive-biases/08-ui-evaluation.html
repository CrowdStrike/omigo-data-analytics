Dashboard & Evaluation Biases

1. Dashboard Color Bias (Red/Green Framing)

Color triggers emotional System-1 responses before rational analysis begins. A green "+5%" feels like a win; gray with confidence intervals feels uncertain.

  • Green +5% after 6 hours (n=200) triggers "ship it!"
  • Gray with CI and progress bar triggers "wait"
  • Same data, opposite decisions
Fix: Default dashboards to neutral colors. Show CIs and sample progress prominently. Reserve green/red for post-hoc confirmed results only.

2. Test Set Leakage / Overfitting to Evaluation

50 iterations on the same test set: accuracy climbs 78% to 89%. Production: stays at 81%. The 8% gap is self-deception.

  • Each "improvement" overfits to test set quirks
  • Production accuracy never moves
  • The gap widens with each iteration
Fix: Hold out a final evaluation set touched only once. Track production metrics independently. If test and production diverge, trust production.
