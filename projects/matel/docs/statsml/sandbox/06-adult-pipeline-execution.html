19b. Adult Census — Pipeline Execution

6 numerical features from the Adult Census dataset (n=32,561) flowing through the full shape classification pipeline. v3-full CNN results only.

1. Age

Type: numerical Shape: right_skew (100%) Gap: NO Valley: NO
Right-skewed continuous ages (17–90) with a working-age bulge peaking around 25–40 and monotone decline toward 90. No gaps or valleys detected — single unimodal segment.
Result: 1 segment → 4 range-based extended features (young, mid, senior, elderly)

2. fnlwgt (Census Weight)

Type: numerical Shape: right_skew (99%) Gap: YES (sparse tail >500k) Valley: NO
Strongly right-skewed with most mass in 100k–250k range and a sparse extreme tail beyond 500k. Gap detection splits into main segment (n=32,400) and extreme weights (n=160). Main segment fits right_skew well.
Domain note: fnlwgt is a sampling weight, not a personal attribute. Predictive use requires domain justification.

3. Education_Num

Type: ordinal Shape: spike (92%) Gap: discrete artifact Valley: structural
16 discrete ordinal levels with prominent peaks at 9 (HS-grad), 10 (Some-college), and 13 (Bachelors). Zero-count bins are artifacts of histogram binning on integer data, not real gaps. Valleys between peaks are structural properties of the education system, not separate populations. Strong monotone relationship with target validates ordinal treatment.
Result: Ordinal dual-path → natural groupings (no_hs, hs_grad, some_college, bachelors, graduate) → 5 extended features

4. Capital_Gain

Type: numerical Shape: zero_inflated (100%) Gap: YES (multiple) Valley: N/A
Extreme zero-inflation (95% zeros) with a second spike at the cap value of 99,999. Gap detection identifies 3 segments: zeros (n=30,913), mid-range gains (n=1,489), and capped values (n=159). The capped group is nearly 100% high-income — an extremely strong signal.
Result: 3 segments via gap splits → 4 extended features (has_gain, gain_small, gain_large, gain_capped)

5. Capital_Loss

Type: numerical Shape: zero_inflated (100%) Gap: YES Valley: possible in non-zero segment
Similar zero-inflation pattern (95.4% zeros) but no cap spike. Gap between zero and first non-zero values creates a clean structural split into zeros (n=31,047) and actual losses (n=1,514). The non-zero segment peaks around $1,500–$2,000 with possible bimodality, though sample size is modest.
Result: 2 segments via gap split → 4 extended features (has_loss, loss_small, loss_typical, loss_large)

6. Hours_per_week

Type: numerical Shape: spike (100%) Gap: NO Valley: structural (spike-created)
Massive spike at exactly 40 hours (~50% of data) with continuous tails on both sides. All bins 1–99 are populated so no gaps exist. Valleys flanking the spike are artifacts of the spike itself, not separate populations. No standard parametric model fits; structural binning (part-time/full-time/overtime) is more appropriate than distributional splitting.
Pipeline note: Spike-at-mode features require domain-informed structural binning rather than the standard shape-split-model path.
