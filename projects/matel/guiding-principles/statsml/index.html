Foundations, profiling, pitfalls, metrics

Key Principles

No Assumptions: Don't assume normal. Don't assume continuous. Don't assume populated. Profile first, then decide what tools apply.
Data Must Earn Its Place: A feature is only used if it demonstrates separation with enough data to back the claim.
Shape Determines Test: A t-test on bimodal data is meaningless. Match the test to the shape and sample size.
Bucket Purity Over Global Metrics: A feature with "no significant difference in means" might still have a range where one class dominates 95%+.
