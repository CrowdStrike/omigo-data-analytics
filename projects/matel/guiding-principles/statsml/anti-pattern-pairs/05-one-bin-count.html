Use One Bin Count for All Features

20 bins for power-law: 1 bin has 80% of data, 19 bins are empty noise

The Anti-Pattern

20 bins for everything — one-size-fits-all. Power-law feature: first bin overwhelms, rest are empty.

Equal-width bins on skewed data produce one overloaded bin and many empty ones — you learn nothing about the distribution's structure.

Domain examples:

  • Income (most clustered low, long tail to millions)
  • Hospital charges (bulk under $10k, outliers to $500k)
  • File sizes (many small files, few massive ones)
  • Any skewed distribution with power-law or exponential tail

The Design Pattern

Multi-resolution: run at multiple bin counts. Equal-count (percentile-width) bins: width encodes density.

Meta-distribution Gini: if > 0.7, feature needs adaptive treatment.
  • Variable-width bins — narrow where data is dense, wide where sparse
  • Each bin holds the same count of observations
  • Width becomes the signal: narrow = high density, wide = low density
  • No wasted bins, no information loss
