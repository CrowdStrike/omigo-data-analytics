Data Center Network

Statistical pitfalls in network telemetry — temporal aliasing, sampling blindness, and the deception of aggregate metrics.

1. Microbursts Invisible at Polling Interval
SNMP polls every 5 seconds; link shows 30% utilization. Reality: 100% for 200ms every second = packet drops + latency spikes. The problem exists BETWEEN the measurements. Polling frequency creates temporal aliasing — sub-second bursts saturate the link but are averaged away by the 5-second sample window. You see "healthy 30%" while users experience drops.
2. ECMP Hash Creates Uneven Load
4 equal-cost paths; hash algorithm sends certain flows always to the same path. One path at 90%, other three at 20%. "Average utilization = 37%" masks one path at failure threshold. ECMP promises equal distribution but hash collisions create persistent imbalance. The average hides that one link is near saturation while others idle.
3. Elephant vs Mice Flows
One 10Gbps backup job = elephant flow. 10,000 small API calls = mice flows. The elephant blocks mice in shared buffers. Average throughput looks fine; tail latency for mice = terrible. A single large flow dominates buffer space, starving thousands of latency-sensitive small flows. Must model BY FLOW TYPE not in aggregate.
4. Buffer Bloat
Switch buffers large — packets queued not dropped. Link looks "healthy" (no drops) but latency is 50ms instead of 0.1ms. Traditional loss-based congestion signals don't fire. Problem invisible to loss metrics, visible only in latency. Monitoring packet loss alone gives false confidence; must track latency as primary congestion signal.
5. Fabric Upgrade Partial-State
Upgrading switches in stages: half network on new firmware, half on old. Routing protocols recalculate; traffic patterns shift during maintenance window. Data collected during upgrade is unrepresentative of steady-state behavior. Must identify and exclude transitional periods from any baseline or capacity analysis.
6. Telemetry Sampling at 100Gbps
Can't mirror 100% of 100Gbps traffic for analysis. Sample 1:1000 packets. Rare attack patterns may not appear in ANY sample. Statistical visibility degrades with speed — faster network = worse security visibility. A 1-in-million event at 100Gbps has near-zero probability of appearing in sampled telemetry.
