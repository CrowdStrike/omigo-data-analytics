Evolution of Computing, Data & Tech

How we got here — the major phases in each strand of the industry, including the ones that ended.

The purpose: factual history rather than commentary. Each page covers the significant phases of one strand, what changed at each step, and what it replaced. Phases that no longer exist are marked rather than quietly omitted — a technology ending is as informative as one surviving, and several ended not by failing but by becoming so ordinary that the name stopped being useful. Every page opens with a timeline showing when each phase began and whether it has ended. Dates are approximate and mark mainstream adoption rather than first release.
LANGUAGES

1. Programming Languages

Machine code through high-level languages, managed runtimes, the scripting boom, and the concurrency and safety generation. Ends with how coding assistance is changing what makes a language a practical choice.

1940s → present
PARADIGMS

2. Programming Paradigms

How code was organised rather than what it was written in: unstructured, procedural, declarative, object-oriented, distributed objects, functional, microservices, serverless. The unit of composition kept changing size.

1950s → present
DATA SCALE

3. Data Footprint

Kilobytes on punched cards to petabyte corpora. Covers what stopped being a constraint at each step, the big data wave as a named movement, and why the term retired once the capability became the default assumption.

1950s → present
ANALYTICS

4. Data Analytics Sophistication

Hand tabulation, statistical inference, Markov models for language, relational OLAP, semi-structured stores, web-scale processing, entity resolution and data fusion, then querying in natural language.

1900s → present
MACHINE LEARNING

5. Machine Learning

The non-neural line: regression, expert systems, decision trees, support vector machines, ensembles and gradient boosting, then the operational layer of serving, drift detection and retraining.

1950s → present
NEURAL NETWORKS

6. Neural Networks & Deep Learning

Three waves separated by two winters. Perceptrons, backpropagation, the pretraining revival, convolutional networks and ImageNet, recurrence and gating, generative models, attention, and scale as strategy.

1957 → present
ARCHITECTURE

7. System Architectures

Mainframes and terminals, client-server, three-tier web, service buses, virtualisation, cloud infrastructure, microservices, serverless, and edge. A pendulum between centralised and distributed.

1960s → present
DEVELOPER TOOLS

8. Coding Tools

Punched cards, terminal editors, centralised then distributed version control, graphical IDEs, code hosting and review, continuous integration, containerised environments, and coding agents.

1950s → present
INTERNET

9. Internet & Communication

Bulletin boards, Usenet and IRC, email, the static web and directories, search, instant messaging, blogs and RSS, social networking, mobile, photo and ephemeral sharing, and algorithmic short video.

1970s → present
PROCESSORS

10. Processors & Compute Hardware

Vacuum tubes to accelerator clusters. Includes the 2004 discontinuity when clock speeds stopped rising, why that forced concurrency into software, and how GPU arithmetic made deep learning practical.

1940s → present
DELIVERY

11. Cloud & Software Delivery

Boxed licences, on-premise enterprise installs, the early hosted-application attempt that arrived too soon, web applications, infrastructure and platforms as services, subscriptions, thin clients, and metered consumption.

1980s → present
STACKS

12. The Default Tech Stack

Vendor-integrated mainframes, proprietary Unix, the Microsoft stack, LAMP, the JVM enterprise stack, convention-driven frameworks, JavaScript everywhere, and the container-plus-Postgres common denominator.

1960s → present
OPEN SOURCE

13. Open Source & Shared Resources

Sharing as the original default, proprietary licensing, copyleft and permissive licences, Linux, Apache and foundation governance, SourceForge to GitHub, commercial support models, open datasets and Kaggle, model hubs, and open weights.

1960s → present
NETWORKING

14. Networking & Data Movement

Dial-up kilobits to 800-gigabit links — roughly a millionfold change in one working lifetime. The switch that stopped networks slowing down as you added computers, glass replacing copper between cities, always-on homes, and why chips now wait on data rather than the reverse.

1960s → present
QUERY LANGUAGES

15. Data Query Languages

Hand-navigated records, the relational break that separated the question from the retrieval strategy, SQL's standardisation, cubes and documents, the brief return to hand-coded execution, purpose-built languages per data model, and SQL as a compilation target.

1950s → present
SEGMENTS

16. Big Tech by Technology Segment

Grouped by what the product is rather than who owns it: hardware vendors, operating systems, portals, search, e-commerce, email, the social graph, video, mobile sharing, recommendation feeds, maps, cloud, and model providers.

1960s → present
FILE FORMATS

17. Data File Formats

Plain text and delimiters that refuse to retire, configuration as its own problem, XML's decade as the universal interchange, JSON winning by being small enough, binary schemas that made independent deployment possible, columnar storage changing what analysis costs, one-record-per-line, table formats that carry their own history, and weights as a storage class.

1960s → present
CROSS-STRANDdraft

18. How Things Happened Together

Three or four strands put on one timeline so the relationship between them shows without being drawn. Four different overlap shapes: the lag between GPUs existing and deep learning using them, query languages accumulating rather than replacing each other, workloads arriving before the tools that serve them, and the one window where every strand turned over at once.
