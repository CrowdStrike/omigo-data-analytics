Spotify Playlists API BACKLOG

Playlist creation, modification, reading, saved tracks, and saved albums. User-curated content vs. algorithmic mixes.

Last verified: August 2026

Overview

The Spotify Web API exposes user-created playlists, saved tracks, and saved albums as first-class resources. This covers content the user intentionally organized — not algorithmic outputs like Discover Weekly or Release Radar, which are not accessible via API despite appearing in the user's library.

Key distinction: User-curated playlists (owned by the user, editable) vs. algorithmic mixes (owned by Spotify, read-only in-app, invisible to API).

OAuth2 Scopes Required:

playlist-read-private playlist-read-collaborative playlist-modify-public playlist-modify-private user-library-read

Pagination: Full track list retrievable with pagination at 100 items per request. Playlists can hold up to 10,000 tracks.

Audio Features per Track:

  • danceability — how suitable for dancing (0-1)
  • energy — perceptual intensity and activity (0-1)
  • valence — musical positiveness (0-1)
  • tempo — BPM estimate
  • acousticness — confidence track is acoustic (0-1)
  • instrumentalness — predicts no vocals (0-1)
  • speechiness — presence of spoken words (0-1)
  • liveness — audience presence probability (0-1)

Business Scenarios:

  • Playlist analytics and mood detection
  • Music recommendation engines
  • User taste profiling over time
Restrictions: 10,000 track limit per playlist. Rate limits not publicly documented but ~180 requests/min observed in practice.
