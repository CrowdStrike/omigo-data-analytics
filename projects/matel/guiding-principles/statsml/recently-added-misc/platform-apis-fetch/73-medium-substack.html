Medium Stories API BACKLOG

Publishing posts, retrieving user info, and managing publications — a write-only model with extreme limitations

Last verified: August 2026

API Overview

Write-only design: Medium's API allows you to push content in but provides almost no way to read content out. You cannot read others' articles, list your own published posts, retrieve stats, search, access comments, or get follower data.

One of the most restricted major platform APIs available. Essentially abandoned since 2017 — no new endpoints, no documentation updates, no versioning changes.

Available endpoints (total: ~5):

  • Get authenticated user info
  • Get user's publications list
  • Create post under user
  • Create post under publication
  • Get publication contributors

Authentication:

  • Integration tokens — self-service from Settings page, for personal use
  • OAuth2 — for third-party apps accessing other users' accounts

Rate limits: No official documentation. Effectively honor-system.

Content format: HTML or Markdown in request body.

Business scenarios:

  • Cross-posting from CMS (WordPress, Ghost, custom)
  • Automated publishing pipelines from internal docs

What you cannot do:

  • Read articles (yours or others')
  • List published articles
  • Get article stats or analytics
  • Search content
  • Access comments or responses
  • Get followers or following lists
  • Edit or delete published posts
