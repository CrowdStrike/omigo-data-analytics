Google Drive API BACKLOG

Platform API Reference

Last verified: August 2026

What It Provides

Files, folders, comments, revisions, permissions, shared drives. Full CRUD on files and metadata. Export Google Workspace files (Docs, Sheets, Slides) to standard formats (PDF, DOCX, XLSX, PPTX). File watching via push notifications (webhooks).

Authentication

  • OAuth 2.0: for user data access
  • Service accounts: for domain-wide delegation (Workspace admin grants)
  • API Key: very limited (public files only)
  • Scopes: drive (full), drive.file (app-created files only), drive.readonly, drive.metadata.readonly, drive.appdata

Granularity

Individual file metadata, content, or both. Partial responses via fields parameter. Change tracking via changes.list with page tokens. Supports resumable uploads for files up to 5TB.

Key Endpoints

  • files.list, files.get, files.create
  • files.update, files.export
  • permissions.create, revisions.list
  • changes.list, channels.watch

Rate Limits

  • 20,000 queries per 100 seconds per project
  • 20 queries per second per user
  • Uploads: 750GB/day per user (Workspace), 15GB/day (free)
  • Push notifications: 10,000 channels per project
  • Export limits: Docs up to 10MB, Sheets up to 10M cells

Business Scenarios

  • Document management systems
  • Automated backup and compliance archival
  • Collaborative workflow tools
  • File sync engines
  • Data pipeline sources (Sheets as data source)

Key Restrictions

Google Workspace files (Docs/Sheets/Slides) have no binary — must export to standard format. Shared drive items owned by organization not individual.
  • Trash auto-deletes after 30 days
  • File watching channels expire (max 24h, need renewal)
  • Cannot search inside file content (only metadata/name)
  • Revision history limited to 100 revisions for non-Workspace files
