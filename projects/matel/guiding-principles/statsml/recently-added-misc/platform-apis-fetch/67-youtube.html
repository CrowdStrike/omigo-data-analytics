YouTube Content API (Data API v3) BACKLOG

Platform API Reference

Last verified: August 2026

What It Provides

Video uploads, metadata updates, captions, playlists, playlist items, channel info, community posts, video categories. Resumable uploads for large files.

Authentication

  • API Key: for public data only (video search, public channel info)
  • OAuth 2.0: for private data and write operations (upload, update, delete)
  • Service accounts: for server-to-server (limited use cases)

Granularity

Video resources with parts system — request only the parts you need (snippet, contentDetails, statistics, status, player, topicDetails). Each part costs different quota units.

Key Endpoints

  • videos.insert — upload
  • videos.list — retrieve video details
  • videos.update — modify metadata
  • search.list — search videos/channels
  • playlists.list — list playlists
  • playlistItems.insert — add to playlist
  • captions.insert — upload captions

Rate Limits (Quota System)

  • Default: 10,000 units per day per project
  • videos.insert (upload): 1,600 units
  • search.list: 100 units
  • videos.list: 1 unit
  • videos.update: 50 units
  • videos.rate (like): 50 units
  • playlists.insert: 50 units
  • captions.insert: 400 units
  • Can request quota increase but rarely granted beyond 1M/day

Business Scenarios

  • Content management systems
  • Automated publishing
  • Analytics dashboards
  • Caption/subtitle management
  • Playlist curation
  • Cross-platform syndication

Key Restrictions

10,000 unit daily quota is very restrictive — only ~6 uploads/day at default. Quota resets at midnight Pacific Time.
  • No access to YouTube Analytics via Data API (separate Analytics API)
  • Upload file size max 256GB
  • Private/unlisted videos only accessible by owner
  • Community posts API limited
