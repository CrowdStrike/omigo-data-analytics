WhatsApp Business API (Cloud API) BACKLOG

Sending and receiving messages at scale via Meta's hosted Cloud API — template-based outbound, webhook-driven inbound.

Last verified: August 2026

API Overview & Conversation Pricing

Conversation Window Model
  • User-initiated: A 24-hour conversation window opens when a user messages the business first. Any message type (text, media, interactive) is allowed within this window.
  • After 24hr window closes: Only pre-approved template messages can be sent. Free-form messaging is blocked until the user responds again.
  • Business-initiated: Requires a pre-approved message template reviewed and approved by Meta (approval can take up to 24hrs).
Pricing is per-conversation, not per-message. Once a conversation opens (user or business-initiated), all messages within that 24hr window are covered by a single conversation charge.
Conversation Categories & Pricing
  • Marketing: Promotions, offers, campaigns — highest cost tier
  • Utility: Order updates, shipping notifications, account alerts
  • Authentication: OTP codes, 2FA verification messages
  • Service: User-initiated conversations — first 1,000/month free
Authentication & Access
  • System User access tokens via Meta Business Suite
  • Business Verification required before going live
  • Webhook-based: receive inbound messages via configured webhook URL
Rate Limits
  • Cloud API: 80 messages/second throughput
  • Messaging limits based on quality rating: 1K → 10K → 100K → Unlimited tiers
Business Scenarios
  • Customer notifications & order updates
  • Appointment reminders
  • 2FA / authentication codes
  • Marketing campaigns (opt-in required)
Restrictions
  • Must comply with Meta Commerce Policy
  • Explicit opt-in required from users before messaging
  • Template approval can take up to 24 hours
  • Phone number must be dedicated — cannot use personal WhatsApp
