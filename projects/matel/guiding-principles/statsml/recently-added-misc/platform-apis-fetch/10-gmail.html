Gmail API BACKLOG

Platform API Reference

Last verified: August 2026

What It Provides

Email messages, threads, labels, attachments, drafts, message history. Full programmatic access to a Gmail mailbox.

Authentication

OAuth 2.0 with granular scopes:

  • gmail.readonly — read all mail
  • gmail.modify — read/write but not delete
  • gmail.compose — create/send only
  • gmail.metadata — headers only, no body
  • gmail.labels — manage labels only
  • gmail.send — send only (no read)

Granularity

Individual messages or full threads. Supports partial responses via fields parameter. Batch requests up to 100 per batch.

Key Endpoints

  • users.messages.list
  • users.messages.get
  • users.threads.list
  • users.labels.list
  • users.drafts.create

Rate Limits

  • 250 quota units per user per second
  • Daily usage limit varies by project (default ~1 billion units/day for most)
  • messages.get = 5 units, messages.list = 5 units, messages.send = 100 units
  • Batch requests count each sub-request individually

Business Scenarios

  • Email analytics
  • Automated responses
  • CRM integration
  • Backup/archival
  • Compliance monitoring
  • Phishing detection

Key Restrictions

  • Requires Google Workspace or personal Gmail account consent
  • Sensitive scope review required by Google for production apps
  • No real-time push for new messages (use pub/sub or polling)
  • Attachment size limit 25MB
  • History ID for incremental sync expires
