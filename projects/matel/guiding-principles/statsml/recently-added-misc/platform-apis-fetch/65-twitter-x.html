Twitter/X Tweets API (v2) BACKLOG

Platform API Reference

Last verified: August 2026
What It Provides
  • Tweets, retweets, replies, quote tweets, thread chains
  • Full-archive search (Academic tier)
  • Filtered stream for real-time matching
Authentication
  • OAuth 2.0 Bearer Token (app-only) for public data
  • OAuth 2.0 PKCE (user context) for posting/DMs
  • App-level for public data, user-level for posting/DMs
Granularity
  • Individual tweet objects with expansions system
  • Request tweet.fields, user.fields, media.fields, place.fields, poll.fields separately
Endpoints
  • GET /2/tweets/:id
  • GET /2/tweets/search/recent
  • GET /2/tweets/search/all (Academic)
  • POST /2/tweets/search/stream (filtered stream)
Rate Limits / Tiers
  • Free: 1,500 tweets/mo read, 1 app, no filtered stream
  • Basic ($100/mo): 10,000 tweets/mo read, 50,000 tweets/mo post (unlikely real usage)
  • Pro ($5,000/mo): 1M tweets/mo read, 300,000 tweets/mo post, full-archive search
  • Enterprise: custom
Business Scenarios
  • Brand monitoring
  • Sentiment analysis
  • Trend detection
  • Academic research
  • Competitive intelligence
Key Restrictions
  • No access to deleted tweets
  • No historical DMs via API
  • Filtered stream rules limited by tier
  • No bulk download of user timelines beyond pagination limits
  • v1.1 endpoints deprecated
