Instagram Insights API

Reach, impressions, engagement, story interactions, and follower demographics — available only for Creator and Business accounts via the Meta Graph API.

What It Provides

Account-level metrics: reach, impressions, profile views, follower count, follower demographics by age/gender/city/country. Media-level metrics: reach, impressions, engagement, saves, shares, comments, likes. Story metrics: exits, replies, taps forward/back. Reel metrics: plays, reach, shares.

Authentication

OAuth via Facebook Login. Requires a Facebook App, Instagram Business or Creator account linked to a Facebook Page. Permissions: instagram_basic, instagram_manage_insights, pages_show_list, pages_read_engagement.

Granularity

Account metrics available in daily, weekly, or 28-day periods. Media metrics are lifetime (cumulative since posting). Stories metrics available only while story is live + 24 hours after. No historical backfill beyond 30 days for time-series account metrics.

Rate Limit

200 calls per hour per user token. Separate from the overall Meta Graph API rate limits (which are per-app).

Business Scenarios

Influencer analytics platforms, brand partnership valuation, content strategy optimization, audience overlap analysis, competitive benchmarking (public metrics only), ROI tracking for sponsored posts.

Restrictions

Personal accounts have zero API access to insights. Follower demographic breakdowns require minimum 100 followers. Story insights disappear after 24 hours past story expiry. Reach and impressions can differ dramatically (reach = unique accounts, impressions = total views including repeats). Cannot access other users' insights — only your own account.

Deprecation Notes

The legacy Instagram API (api.instagram.com) was fully deprecated in 2024. All access now goes through the Meta Graph API (graph.facebook.com). The Basic Display API was also sunset — replaced by Instagram API with Facebook Login.
