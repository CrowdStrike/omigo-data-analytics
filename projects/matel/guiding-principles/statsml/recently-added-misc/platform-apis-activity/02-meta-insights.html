Meta Insights API (Facebook / Instagram)

Page and post analytics via the Graph API — reach, impressions, engagement, audience demographics
What the API Provides
  • Page-level: reach, impressions, engaged users, page views, fan count changes
  • Post-level: impressions, reach, engagement (reactions, comments, shares)
  • Instagram: reach, impressions, profile views, follower demographics (age/gender/city)
  • Stories/Reels: exits, replies, taps forward/back, reach
  • Audience breakdown: age ranges, gender, top cities, top countries
  • Available via GET /{page-id}/insights and GET /{ig-media-id}/insights

Access & Authentication
  • OAuth 2.0 with Facebook Login
  • Requires a Facebook Business account linked to a Page
  • App must pass Facebook's App Review for pages_read_engagement, read_insights permissions
  • Instagram insights require instagram_basic + instagram_manage_insights permissions
  • Page access tokens (long-lived: 60 days, then refresh)
  • Rate limits: 200 calls/user/hour for page insights, 4800 calls/day per app for IG
Token lifecycle: Short-lived token (1-2 hrs) → exchange for long-lived (60 days) → refresh before expiry. System user tokens (for server-to-server) do not expire but require Business Manager setup.
Rate limit structure: Graph API uses a sliding-window model. Exceeding limits returns HTTP 429 with x-business-use-case-usage header showing percentage consumed per business object.
Granularity & Limitations
  • Page metrics: available in day, week, days_28 periods
  • Post metrics: lifetime aggregates only (no time-series per post)
  • Data available after 24-48 hours (not real-time)
  • Instagram insights only available for Business/Creator accounts with 100+ followers
  • Historical data: up to 2 years for page-level, 2 years for post-level
  • Metrics can be "gated" — some require specific permission scopes
  • Demographic data only shown if audience is 100+ people in a bucket (privacy threshold)
Key constraint: Post-level metrics are lifetime-only. You cannot ask "how did this post perform on day 3 vs day 7." You get a single cumulative number. To build a time-series, you must poll repeatedly and store deltas yourself.
Privacy thresholds: If fewer than 100 people in a demographic bucket (e.g., women 18-24 in Portland), Meta suppresses that row entirely. Small-audience pages get very sparse demographic data.
Business Scenarios & Deprecation Notes
  • Content performance dashboards, audience growth analysis, cross-platform comparison
  • Graph API version deprecation cycle: each version supported ~2 years, then sunset
  • v18.0 (current as of 2024) — older versions return errors after deprecation
  • Facebook Analytics (the standalone product) was deprecated June 2021
  • CrowdTangle (social listening) deprecated June 2024, replaced by Meta Content Library
  • Organic reach metrics have declined over time — comparing across years is misleading
Deprecation trap: If you hardcode a Graph API version (e.g., /v16.0/), your integration silently breaks ~2 years later. Use versionless calls cautiously — they default to the oldest supported version, which itself eventually sunsets.
Organic reach decline: A page that had 15% organic reach in 2014 may see 2-3% in 2026 for the same content quality. Year-over-year reach comparisons without controlling for algorithm changes are meaningless.
