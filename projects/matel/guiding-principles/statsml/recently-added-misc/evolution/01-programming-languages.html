Evolution of Programming Languages

From toggling switches to describing intent in English — roughly seventy-five years of raising the abstraction level.

Dates are approximate and mark mainstream adoption rather than first release. Bars in red ended as mainstream practice; orange survives in specific niches only. An arrow at the right edge means the phase is still ongoing.

The Eras

EraWhat changed
1940s – 1950s
Machine code & assemblygone
Raw opcodes, assembler mnemonics
Programs were written in the instruction set of one specific machine. Moving to different hardware meant rewriting from scratch, and the programmer managed every register and memory address by hand. Productivity was measured in instructions per day.
Late 1950s
First high-level languages
Fortran, Lisp, COBOL, ALGOL
The compiler arrived, and with it the idea that source code could outlive the machine it was written for. Fortran brought formula notation to scientific work, COBOL brought readable syntax to business records, and Lisp introduced recursion, garbage collection and treating code as data — ideas the mainstream took forty years to absorb.
1970s
Structured & systems programming
C, Pascal, Smalltalk
Goto-driven control flow gave way to loops, functions and blocks. C in particular hit a durable balance: portable across machines, yet close enough to the hardware to write an operating system in. Most languages in use today are still compiled or interpreted by something written in C.
1980s
Object orientation goes mainstream
C++, Objective-C, Ada
As programs grew past what one person could hold in mind, the organising unit became the object — data bundled with the code permitted to touch it. The motivation was managing scale in large teams rather than any gain in expressive power.
1990s
Managed runtimes & the scripting boom
Java, Python, JavaScript, PHP, Perl, Ruby, Visual Basic
Two shifts at once. Java made the virtual machine standard, so memory management became the runtime's job and one binary ran anywhere. Meanwhile the web created demand for languages optimised for speed of writing over speed of execution. The trade was deliberate: hardware was getting cheaper faster than programmers were.
2000s
Web frameworks & managed enterprise stacks
C#, Ruby on Rails, Scala, ActionScript
The unit of productivity became the framework rather than the language. Convention-over-configuration meant a working application in an afternoon, and the JVM began hosting languages other than Java, separating the runtime from the syntax written on top of it.
2010s
Concurrency, safety, and gradual types
Go, Rust, Swift, Kotlin, TypeScript
Single-core clock speeds had stopped improving, so concurrency moved into the language itself — goroutines and channels in Go, ownership and borrowing in Rust. Rust made memory safety a compile-time guarantee without a garbage collector, and TypeScript demonstrated that types could be layered onto an existing dynamic language incrementally.
2020s
Python concentrates the AI stack; assistance loosens language choice
Python over C++/CUDA; renewed activity in R, JavaScript, and others
Machine learning work concentrated on Python, largely because the libraries were there, with the numerical operations delegated to C++ and CUDA underneath. Python became the coordination layer rather than where the computation happens. Two things are worth separating from that: Python's share is a matter of popularity in this domain, not displacement elsewhere — JavaScript still runs the browser, SQL still queries the data, C still underpins the runtimes. And coding assistance changes the economics of the choice: when a model can produce working code in a language the author does not know well, familiarity stops being the deciding factor, so work continues in R, JavaScript and other established languages rather than migrating for want of fluency. How durable that effect proves is not yet clear.

What Disappeared

Ended as mainstream practice:
  • Hand-written assembly for application work — survives in compilers, firmware, and hot loops, but no longer how programs are written
  • Punched cards and batch submission — the edit-compile cycle went from overnight to sub-second, which changed how people debug more than any language feature
  • Visual Basic and VB6 — dominant for internal business tools, then discontinued outright
  • Flash and ActionScript — ran most interactive content on the web, then removed from every browser at the end of 2020
  • Perl as a default choice — the standard glue language of the early web, displaced by Python for readability
  • Applets and client-side Java in the browser — the original "write once, run anywhere" delivery model, now entirely gone
  • CoffeeScript — a case of absorption rather than replacement: several of its features were adopted into JavaScript itself, which removed the reason to use it separately.
Alive, but only in niches:
  • Fortran — still runs weather and physics codes where the numerical libraries are decades-validated
  • COBOL — still runs core banking and government records, largely because rewriting carries more risk than maintaining
  • Pascal and Delphi — the teaching language of a generation, now confined to legacy Windows applications
  • Objective-C — supported for existing Apple codebases, superseded by Swift for new work
