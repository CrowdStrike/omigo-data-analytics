39. Filename Naming Conventions

Consistent, sortable, grep-friendly naming for pipeline artifacts, configs, models, and docs.

Core tension: Human readability vs machine sortability. Filenames are the first metadata layer — they should encode enough to find, sort, and deduplicate without opening the file.

Principles (Draft)

1. Filenames sort lexicographically in the order you'd read them.

2. No spaces, no uppercase, no special chars beyond hyphen/underscore/dot.

3. Prefix encodes sequence/priority; suffix encodes type/version.

4. A filename alone (without its directory path) should be locally unambiguous.

Anti-Patterns

• final_v2_FINAL_new.csv — no versioning discipline

• data (1).json — spaces, parens, no semantics

• a.py, b.py, c.py — zero information content

• Mixing conventions within one directory level
