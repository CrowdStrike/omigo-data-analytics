Evolution of Processors & Compute Hardware

Vacuum tubes to accelerator clusters — processors, cores and accelerators, and the moment single-core speed stopped improving.

Dates are approximate and mark mainstream adoption rather than first release. Bars in red ended as mainstream practice; orange survives in specific niches only.

The Eras

EraWhat changed
1971 onward
The microprocessor
Integrated circuits, CPU on one chip
Putting a processor on a single chip made computers a commodity component. The steady doubling of transistor density that followed became the background assumption of the whole industry: software could be written for hardware that did not exist yet, on the expectation it would arrive.
1975 – 2004
Faster clocks each yeargone
Frequency scaling, deeper pipelines
For roughly three decades performance improvements arrived largely through higher clock speeds, so existing single-threaded programs got faster without modification. This ended when power density and heat made further frequency increases impractical — the most consequential discontinuity in the industry's hardware history.
1996 onward
Parallel hardware for graphics
Dedicated GPUs, programmable shaders
Rendering demanded the same operation applied to millions of pixels, so GPUs were built with many simple cores optimised for throughput rather than latency. Programmable shaders then made that parallel capacity accessible for arbitrary computation.
2005 onward
More cores instead of faster ones
Multicore CPUs, SMT
With frequency capped, vendors added cores. Performance gains stopped being free: software had to be written concurrently to benefit, which is what pushed concurrency into languages and runtimes and made parallel thinking a general requirement rather than a specialism.
2007 onward
General computation on GPUs
CUDA, OpenCL, tensor cores
A programming model for general-purpose GPU work exposed that hardware to scientific and then machine learning workloads, whose core operation — large matrix multiplication — matched the architecture closely. This is the hardware precondition for deep learning: the same algorithms had existed for years and became practical when the arithmetic got roughly two orders of magnitude cheaper.
2008 onward
Efficiency as the design target
ARM, mobile SoCs, integrated everything
Battery-powered devices made performance per watt the objective rather than peak throughput, and systems-on-chip integrated CPU, GPU, memory controller and signal processors onto one die. That efficiency focus later moved back into laptops and servers, where power and cooling dominate operating cost.
2016 onward
Purpose-built accelerators
TPUs, NPUs, high-bandwidth memory
Chips designed specifically for tensor operations traded generality for efficiency on one workload. The binding constraint also shifted: for large models, moving data between memory and compute — and between chips — now limits performance more often than arithmetic capability does, which is why interconnect bandwidth has become a headline specification alongside arithmetic capability. The networking and data-movement side of that constraint is covered as its own strand.
1940s – 1950s
Tubes and rewiringgone
Vacuum tubes, plugboards
Machines filled rooms, consumed enormous power, and failed frequently as tubes burned out. Reprogramming sometimes meant physically rewiring the machine. Reliability, not speed, was the binding constraint.
1950s – 1960s
Transistorsgone
Discrete transistors, magnetic core memory
Replacing tubes with transistors cut power and failure rates dramatically and shrank machines from rooms to cabinets. Computers became something an organisation could own and operate continuously rather than a research instrument.

What Disappeared

Ended as mainstream practice:
  • Vacuum tubes and plugboard programming — machines reconfigured by physically moving cables
  • Magnetic core memory — individually threaded ferrite rings, replaced by semiconductor memory
  • Free single-threaded speedups — the assumption that next year's processor would run today's code faster, ended around 2004
  • The dedicated maths coprocessor — floating point as a separate purchasable chip, absorbed into the CPU
  • Dennard scaling — the relationship that kept power density constant as transistors shrank, which stopped holding
  • Spinning disks in performance-sensitive systems — displaced by flash for anything latency-dependent
Alive, but only in niches:
  • Mainframe processors — still manufactured for transaction workloads with distinctive reliability requirements
  • FPGAs — reconfigurable logic, used in networking, trading and signal processing where fixed silicon is too rigid
  • Digital signal processors — still ubiquitous but invisible, embedded inside larger systems on chip
