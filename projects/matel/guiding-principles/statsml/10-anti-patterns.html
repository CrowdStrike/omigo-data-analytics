Anti-Patterns & Design Patterns for Data Systems

Common mistakes in data collection, analysis, and ML — paired with the correct design. If you see yourself on the left: switch to the right.

DATA COLLECTION

1. Impute All Missing Values with Column Mean

Destroys the signal that absence carries — missingness is often the strongest predictor.

4. Profile the Entire Column as One Distribution

5. Use One Bin Count for All Features

STATISTICAL TESTING

7. Report P-Value Without Effect Size

At n=100,000: enrichment 1.006× is "significant" but useless for classification.

effect size Bonferroni practical significance
STATISTICAL TESTING

8. Fine-Bucket Rare Classes

20 buckets × 0.01% positive = 12 positives per bucket. Below any statistical minimum.

rare events Mann-Whitney minimum n
STATISTICAL TESTING

9. Check A/B Test Results Daily Until Significant

Peeking inflates FPR from 5% to 25-50%. Not computing power upfront means you don't know how long to run.
