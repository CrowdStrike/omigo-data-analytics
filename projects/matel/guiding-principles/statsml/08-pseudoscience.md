# Pseudoscience in Data Analysis

**Page type:** grid page (card navigation grid, 3 columns)
**HTML title tag:** Pseudoscience in Data Analysis

**Subtitle:** Practices that LOOK scientific (use numbers, charts, p-values) but are actually cargo-cult reasoning — conclusions without valid methodology. Common in industry, research, and especially in fields where someone "looked successful" and reverse-engineered a story.

## Callout (philosophy box)

**The litmus test:** (1) Can the claim be disproven? If not → pseudoscience. (2) Is there a control group / counterfactual? If not → anecdote, not evidence. (3) Was the analysis plan defined BEFORE seeing data? If not → p-hacking / narrative fitting. (4) Does the person promoting it benefit from you believing it? Check evidence 10× harder. (5) Would you bet your own money at fair odds? If not → you don't actually believe it, you just like the story.
