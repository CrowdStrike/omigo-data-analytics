10. PCA (Principal Component Analysis)

Finds directions of maximum variance — assumes linear relationships and meaningful variance
  • Assumes linear relationships: PCA finds linear combinations of features. Non-linear structure (curves, clusters) is invisible — variance along a curve gets split across multiple components.
  • Assumes variance = importance: The first PC captures the direction of highest variance. But if a noisy feature has high variance and the signal feature has low variance, PCA puts noise first.
  • Requires feature scaling: Features with larger ranges dominate PCs entirely. Income (0–1M) will be PC1; age (0–100) will be noise. Must standardize first.
  • Assumes continuous features: Binary/categorical features encoded as 0/1 create artificial directions. One-hot encoded features with 50 categories dominate the PC space.
  • Interpretability collapses: PC1 = 0.3×age + 0.7×income - 0.2×cholesterol. What does this mean? Nothing a domain expert can act on. Original feature meaning is destroyed.
  • Violation: Non-linear data (e.g., two spirals, concentric rings) → PCA projects onto a line through the middle, mixing classes completely. High-variance noise → signal buried in later PCs that get discarded.
  • Real example: Gene expression data with 20K features. PCA reduces to 50 PCs. But the cancer signal is in 5 low-variance genes — PCA discards them because batch effects (technical noise) have higher variance.
  • Alternatives: Non-linear → use t-SNE/UMAP for visualization, kernel PCA for reduction. Categorical data → MCA (Multiple Correspondence Analysis). When variance ≠ importance → supervised feature selection instead.
