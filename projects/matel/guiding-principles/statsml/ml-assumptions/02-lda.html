2. Linear Discriminant Analysis (LDA)

Assumptions & What Breaks
  • Multivariate normality: each feature must be normal WITHIN each class separately. Not overall.
  • Equal covariance matrices: both classes share the same variance-covariance structure.
  • No multicollinearity: singular covariance matrix makes inversion fail.
  • Sufficient n > features: need more samples than features per class for stable estimates.
  • Violation: non-normal features produce suboptimal boundary; bimodal data gets systematic misclassification.
  • Violation: unequal covariance tilts the boundary, one class gets consistently misclassified.
  • Verify: Shapiro-Wilk per feature per class, Box's M test for covariance equality.
  • Alternative: QDA (relaxes covariance), non-parametric classifiers, or density estimation per range.

Real example: Age is bimodal within the positive class (young risk + elderly risk). LDA fits a single Gaussian, places the boundary at mean=52, missing both subgroups.
