1. Logistic Regression

Assumptions & What Breaks
  • Linear log-odds: each feature must have linear relationship with log-odds of outcome. Non-linear signal is invisible.
  • No multicollinearity: correlated features produce unstable coefficients that flip signs randomly.
  • Independence: observations must be independent (no clustering, no repeated measures).
  • Sufficient n: need 10-20 events per predictor. 5 features = min 50-100 positive cases.
  • No extreme outliers: single value (cholesterol=900) can dominate the entire coefficient.
  • Violation: assigns zero weight to features with strong LOCAL signal (e.g., U-shaped or range-specific).
  • Verify: Box-Tidwell test for linearity, VIF < 5, Cook's distance for influence.
  • Alternative: range-based binary features, GAM, or penalized regression.

Real example: Logistic regression on bimodal cholesterol: coefficient = 0.02, looks insignificant. But the [240-320] range has 76% positive class. The model cannot see range-specific signal.
