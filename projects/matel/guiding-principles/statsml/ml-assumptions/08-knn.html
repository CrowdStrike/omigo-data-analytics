8. K-Nearest Neighbors

Assumptions & What Breaks
  • Feature scaling REQUIRED: ALL features must be on same scale. High-magnitude features dominate distance.
  • Meaningful distance: "nearby" must mean "similar." Categorical/mixed types break this.
  • Low dimensionality: curse of dimensionality: in high-D, ALL points are approximately equidistant.
  • Dense coverage: training data must densely cover feature space. Sparse regions = unreliable predictions.
  • No irrelevant features: every feature contributes equally to distance. Noise dimensions obscure true neighbors.
  • Violation: with 50 features, nearest neighbor is barely closer than farthest point. KNN degrades to random voting.
  • Verify: features scaled, n >> 2^d, k-nearest distances small vs overall spread.
  • Alternative: tree-based for high-D, feature selection first, range-based features reduce dimensionality.

Real example: 30 features, 500 samples. Mean distance to nearest neighbor: 4.82. Mean distance to farthest point: 5.01. Ratio = 0.95. "Nearest" is meaningless.
