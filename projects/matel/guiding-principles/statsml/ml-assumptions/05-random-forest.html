5. Random Forest

Assumptions & What Breaks
  • Feature relevance: with many irrelevant features, random subsets may miss the important ones.
  • Sufficient data: each tree sees ~63% (bootstrap). Small n = repetitive trees = no ensemble benefit.
  • Independent errors: averaging only helps if trees make DIFFERENT mistakes. Dominant features reduce diversity.
  • No extrapolation: cannot predict beyond training range. cholesterol=800 (unseen) gets same prediction as max(train).
  • Violation: masks per-tree overfitting but doesn't fix it. Individual trees still split on noise.
  • Violation: black-box. Cannot explain WHY a prediction was made or which range matters.
  • Verify: OOB error, feature importance stability, training range vs deployment range.
  • Alternative: range-based validated features for explainability and statistical rigor.

Real example: RF predicts "low risk" for cholesterol=750 because max training value was 603. Model confidently extrapolates from the 580-603 region (which was low-risk older patients).
