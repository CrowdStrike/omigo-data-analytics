7. Support Vector Machines

Assumptions & What Breaks
  • Feature scaling REQUIRED: distance-based. Unscaled features with larger range dominate the margin entirely.
  • Meaningful distance: categorical features as integers create false distance (cat 1 vs cat 3 is NOT 2x cat 1 vs 2).
  • Appropriate kernel: linear kernel assumes linear separability. Wrong kernel = boundary can't represent true separation.
  • Moderate dimensionality: in very high-D, all points equidistant. "Margin" concept becomes meaningless.
  • No heavy outliers: support vectors define boundary. Outlier support vectors distort everything.
  • Violation: feature with range [0, 1M] makes features with range [0, 1] completely invisible.
  • Verify: confirm scaling, no categorical-as-ordinal, try multiple kernels with CV.
  • Alternative: tree-based for mixed types, range-based features for explainability. SVM is O(n^2).

Real example: Income (range 0-200K) and age (range 18-90) unscaled. SVM margin determined entirely by income. Age has zero influence on the boundary despite being highly predictive.
