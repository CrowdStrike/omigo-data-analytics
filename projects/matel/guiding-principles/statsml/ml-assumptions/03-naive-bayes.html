3. Naive Bayes

Assumptions & What Breaks
  • Feature independence: ALL features must be conditionally independent given class. P(X1,X2|Y) = P(X1|Y) * P(X2|Y).
  • Correct density model: Gaussian NB assumes normality per class. Wrong density = wrong P(feature|class).
  • No zero-frequency: unseen feature values get probability zero, killing entire class probability.
  • Violation: correlated features (e.g., weight + BMI) double-count evidence, making classifier overconfident.
  • Violation: bimodal feature assumed normal means the valley between modes gets HIGH probability (wrong).
  • Verify: within-class correlation matrix, Q-Q plots per feature per class.
  • Alternative: logistic regression (handles correlations), KDE-based density, range-based features.

Real example: Systolic BP and diastolic BP (r=0.78) both included. NB treats them as independent evidence, producing P(disease) = 0.99 when true probability is 0.65.
