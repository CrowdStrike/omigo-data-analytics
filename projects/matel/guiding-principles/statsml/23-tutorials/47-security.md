# Security

**Page type:** grid page (tutorials category grid: single flat 4-column nav-grid of cards with topic tags)
**HTML title tag:** Security

**Subtitle:** How attackers break systems and how defenders think — starting from the everyday things anyone would recognise, then working outward to web attacks, cloud permissions, supply-chain trust, and the limits of old encryption.

## Card ordering

Cards run layman-first: the techniques anyone would recognise from daily life (a helpdesk phone call, a router's default password, a home camera) come before the ones that need a developer's or cloud engineer's context (IAM policies, build provenance, side channels). The colored `.card-num` labels carry the grouping, so the order is by familiarity, not by label.
