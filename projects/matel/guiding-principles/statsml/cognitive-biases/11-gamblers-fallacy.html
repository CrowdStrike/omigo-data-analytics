Gambler's Fallacy

The belief that past outcomes change future odds in independent events. The universe doesn't keep a ledger and doesn't owe you anything.

Independent Events Don't Accumulate

Played lottery daily for 10 years (3,650 tickets). Feels like "investment" building toward a payoff. Today's odds: still exactly 1-in-a-million. Same as day 1. The 3,649 losses are invisible to today's draw.

In data: Roulette shows 7 reds in a row. Half the table bets on black ("it's due"), half on red ("it's a streak"). Both are wrong. The casino displays the board precisely because it triggers both fallacies and increases betting volume.

Real damage: People treat independent events as a running score. "I've tried N times so I'm N steps closer." No. If each trial is independent, attempt #1 and #3,650 have identical odds.
Ask: "Does the next trial know about previous ones?" If no — if each event is independent — then streaks and droughts are stories. The past doesn't vote on the future.
