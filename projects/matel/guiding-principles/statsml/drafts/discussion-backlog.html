30. Monads: Composable Effect Tracking

31. Functional Programming & Immutability

Pure functions, immutable data, composition. Functional core / imperative shell. Prevents mutation bugs, enables caching, parallelization, and natural lineage.

32. Partial Ordering & Replication Lag

Total ordering is a fiction in distributed systems. Accept partial order, design for commutative ops, watermarks, and consistent snapshots. Replication lag creates impossible states.

33. Data Collection Window Cost

In software, mistakes cost compute time. In data work, mistakes cost calendar time you cannot recover. Wrong schema = months lost. No parallelization fixes it.

34. Negative Class Subsampling

35. Permutation Test

Distribution-free hypothesis testing by shuffling labels. No parametric assumptions required — let the data define its own null. When to prefer over t-test/Mann-Whitney.
