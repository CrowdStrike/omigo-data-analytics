Dissecting Popular Metrics

Question each metric: what it assumes, when it lies, what it hides, and what breaks it.

Goal

For each metric, build a one-page card that covers: formula, distributional assumptions, failure modes, when it misleads, what it optimizes vs what you think it optimizes, and a concrete example where it gives the wrong answer.

Approach per Metric

  • Formula — write it out, identify each component's assumption
  • Hidden assumptions — what must be true for this metric to be meaningful?
  • Failure mode — concrete scenario where optimizing this metric produces a bad outcome
  • Goodhart's Law angle — how does it break when it becomes the target?
  • Distribution sensitivity — how does skew, imbalance, or outliers distort it?
  • What to use instead — when this metric fails, what's the better alternative?
  • Visual — one chart showing the pathological case
