35. Permutation Test

Non-parametric significance testing via label shuffling

STUB — To Be Expanded

Core Idea

Problem: Many statistical tests assume distributional properties (normality, equal variance). When these assumptions fail, p-values are unreliable.

Solution: Permutation tests make no distributional assumptions. They estimate the null distribution empirically by shuffling labels and recomputing the test statistic thousands of times.

  • Shuffle pos/neg labels randomly
  • Recompute test statistic on shuffled data
  • Repeat 1000–10000 times → empirical null distribution
  • p-value = fraction of permuted statistics ≥ observed

When to use: Small n, unknown distribution shape, or as validation alongside parametric results.

Key Questions

  • How many permutations are needed for stable p-value estimates?
  • When does permutation testing add value over Mann-Whitney?
  • How to handle multiple ranges efficiently (computational cost)?
