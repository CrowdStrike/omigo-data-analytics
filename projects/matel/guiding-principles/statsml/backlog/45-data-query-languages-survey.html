Data Query Languages

Each language kind embeds a different assumption — top-down declaration vs bottom-up pipeline, optimiser-driven vs hand-planned, condition-based vs resemblance-based.

01

SQL

Top-down, declarative. State the result, let the optimiser find the path. Outlived every engine underneath it.

02

Pipeline Log Languages (SPL, KQL, LogScale)

Bottom-up, pipe-based. Narrow a stream stage by stage — each operator transforms the previous output.

03

MapReduce

Hand-planned distributed execution. You are the optimiser. The one clear reversal — proved wrong.

bottom-up hand-planned retired
04

Pig Latin

Bottom-up dataflow DAGs. Transitional — proved SQL should compile to distributed plans, then was replaced by exactly that.

bottom-up dataflow retired
05

SQL on Distributed Engines (Hive, Spark, Trino, BigQuery)

Top-down SQL compiled to distributed plans. The language stayed, the engines kept changing underneath.
