8. TOML

Explicit, minimal configuration format.

Core trade-off: No surprises — every type is explicit and what you see is what you get — but deeply nested structures become verbose and awkward.
What It Is Tom's Obvious, Minimal Language — a configuration format created in 2013 as a reaction to YAML's implicit typing problems. Values always have unambiguous types. Strings are always quoted, integers and floats are syntactically distinct, and dates are a first-class type.
Structure / Syntax Key-value pairs: key = "value". Tables (sections): [section]. Arrays of tables: [[array]]. Strings in quotes, integers without, floats with decimal point. Booleans: true/false. Dates: 1979-05-27T07:32:00Z. Comments with #. No indentation significance.
Strengths Explicit types — no implicit coercion, no Norway problem. Clear and readable table syntax. Comments supported. First-class date/time type. Small spec that parsers can implement fully. What you write is exactly what you get — no surprises.
Weaknesses Deeply nested tables require verbose repeated headers ([a.b.c.d]). Less widespread tooling than YAML or JSON. Arrays of tables syntax is confusing to newcomers. Not suitable for deeply hierarchical data. Limited ecosystem for schema validation.
Business Use Case Rust ecosystem (Cargo.toml). Python packaging (pyproject.toml). Application configuration where correctness matters more than expressiveness. Any config where YAML's implicit typing has caused bugs and the team wants explicit guarantees.
Example 
# Everything is explicit — no type surprises
[project]
name = "my-app"
version = "3.10"        # String! Not float 3.1
python-requires = ">=3.8"

[project.authors]
name = "Alice"
email = "alice@example.com"

[server]
host = "0.0.0.0"
port = 8080             # Integer, explicitly
debug = false           # Boolean, explicitly
started = 2024-03-15T10:00:00Z  # Date, first-class

[[server.routes]]
path = "/api/users"
methods = ["GET", "POST"]

[[server.routes]]
path = "/api/health"
methods = ["GET"]
Compare to YAML: version: 3.10 would silently become 3.1. In TOML, "3.10" stays "3.10" because strings require quotes.
