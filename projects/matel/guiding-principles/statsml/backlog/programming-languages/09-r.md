### Code block (below the canvas, `pre` with `#f8f9fa` background, 0.82rem, 12px padding, 4px radius)

```
library(ggplot2)

# Grammar of graphics: data + aesthetics + geometry
ggplot(diamonds, aes(x = carat, y = price, color = cut)) +
  geom_point(alpha = 0.3) +
  geom_smooth(method = "lm") +
  facet_wrap(~cut) +
  theme_minimal()

# One-liner statistical test
t.test(mpg ~ am, data = mtcars)  # automatic vs manual
# p-value, CI, means — all in one call
```
