# 6. Go

**HTML title tag:** 6. Go

**Subtitle:** Event streams and microservices — channels, no exceptions, small modular functions

## Callout (philosophy box)

**Core trade-off:** Simplicity enforced by the language. No generics (until recently), no exceptions, no inheritance. Goroutines and channels as first-class concurrency primitives. Compiles fast, deploys as a single binary. Opinionated by design.

## What It Is

A statically-typed, compiled language created at Google (2009). Designed for large codebases maintained by large teams. Deliberately simple — features were left out on purpose. Compiles to a single static binary with no external dependencies.

## Unique Contribution

Goroutines + channels for lightweight concurrency (spawn millions of goroutines cheaply). No exceptions — explicit error returns force you to handle every failure. Opinionated simplicity (one way to format, one way to loop). Single-binary deployment. Built for microservices and event streaming at scale.

## Strengths

Blazing fast compilation, excellent built-in concurrency, simple syntax anyone can read, static binary deployment (no dependency hell), built-in formatting (gofmt), great standard library, cross-compilation trivial.

## Weaknesses

Verbose error handling (if err != nil on every other line), limited expressiveness, no sum types or algebraic data types, generics arrived late and are limited, no ternary operator, interface satisfaction is implicit (confusing for newcomers).

## Business Use Case

Microservices (Kubernetes, Docker, Istio are all Go), CLI tools (Terraform, Hugo), event stream processing, infrastructure and DevOps tooling, API gateways, network services at scale.

## Example

Code block (`<pre><code>`):

```go
package main

import "fmt"

func producer(ch chan<- int) {
    for i := 0; i < 5; i++ {
        ch <- i * 10  // Send to channel
    }
    close(ch)
}

func main() {
    ch := make(chan int)

    go producer(ch)  // Launch goroutine — costs ~2KB

    // Receive until channel closed
    for val := range ch {
        fmt.Println("Received:", val)
    }
    // No locks, no shared memory — communicate via channels
}
```
