9. R

Statistical computing and science — C wrapper focused on stats, not on software engineering

Core trade-off: Built by statisticians for statisticians. Every statistical test and visualization is a function call away. Not designed as a general programming language — and it shows. Domain depth over language elegance.
What It Is A dynamically-typed, interpreted language designed for statistical computing and graphics. Descended from S (1976). Vectors are the fundamental data type, not scalars. Most heavy computation delegates to C/Fortran underneath. Interactive by nature (REPL-first).
Unique Contribution Statistical computing as the primary design goal — not a general language with stats bolted on. ggplot2 grammar of graphics for principled visualization. C/Fortran wrappers for scientific computation. CRAN ecosystem with 20,000+ peer-reviewed statistical packages covering every method published in journals.
Strengths Unmatched statistical library depth (every test, every model), ggplot2 for publication-quality visualization, CRAN packages are peer-reviewed, interactive exploration in RStudio, data frames as first-class citizens, formula syntax for models (y ~ x1 + x2).
Weaknesses Inconsistent syntax (5 assignment operators: =, <-, <<-, ->, ->>), poor software engineering practices in most R code, slow for non-vectorized operations, copy-on-modify semantics waste memory, 1-indexed arrays, not designed as a general-purpose language.
Business Use Case Academic research and publications, biostatistics and clinical trials (FDA submissions), actuarial science, epidemiology, data visualization for reports, exploratory data analysis, anywhere the analysis matters more than the engineering.
Example 
library(ggplot2)

# One line: full statistical test
t.test(treatment$score, control$score, paired = FALSE)

# Grammar of graphics — layered, principled visualization
ggplot(sales_data, aes(x = month, y = revenue, color = region)) +
  geom_line(linewidth = 1.2) +
  geom_point(size = 2) +
  facet_wrap(~product_category) +
  theme_minimal() +
  labs(title = "Revenue by Region",
       subtitle = "Faceted by product category")

# Linear model in one line
model <- lm(price ~ sqft + bedrooms + location, data = housing)
summary(model)  # Full regression table with p-values
