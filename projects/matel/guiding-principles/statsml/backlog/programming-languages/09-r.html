Built by statisticians for statisticians. Every test is a function call away.

  • ggplot2 — grammar of graphics, layered visualization
  • CRAN — 20,000+ peer-reviewed packages

library(ggplot2)

# Grammar of graphics: data + aesthetics + geometry
ggplot(diamonds, aes(x = carat, y = price, color = cut)) +
  geom_point(alpha = 0.3) +
  geom_smooth(method = "lm") +
  facet_wrap(~cut) +
  theme_minimal()

# One-liner statistical test
