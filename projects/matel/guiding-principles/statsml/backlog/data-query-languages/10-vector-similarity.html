11. Vector Similarity Search

Retrieval by resemblance rather than by stated condition
Not a query language in the traditional sense. You don't state conditions — you provide an example and get back the closest matches. No guarantee any of them actually qualify for your intent. Different in kind from declarative querying.
What It Is A retrieval paradigm where data is encoded as high-dimensional vectors (embeddings) and queries find the nearest neighbors by geometric distance — cosine similarity, Euclidean (L2), or dot product.
Core Idea Encode data as vectors using embedding models. Find nearest neighbors by distance metric. No boolean conditions — similarity is a continuous score, not a binary match. Approximate nearest neighbor (ANN) indexes trade precision for speed.
Strengths Handles semantic similarity — meaning, not just keywords. Works on unstructured data (text, images, audio). Enables RAG (Retrieval-Augmented Generation). Finds relationships that keyword search misses. Scales with ANN indexes (HNSW, IVF).
Weaknesses No precision guarantee — closest does not mean correct or relevant. Requires embedding model selection and maintenance. Index maintenance and rebuild costs. No native boolean logic (requires hybrid search). Results are hard to explain or debug. Distance thresholds are arbitrary.
Business Use Case Semantic search engines, RAG pipelines for LLM grounding, recommendation systems (similar items/users), duplicate and near-duplicate detection, image similarity search, anomaly detection by distance from cluster centers.
Example 
-- Pseudocode: vector similarity search

-- 1. Encode the query
query_vector = embed("shoes comfortable for walking long distances")

-- 2. Search nearest neighbors (cosine similarity)
SELECT product_id, product_name, description,
       cosine_similarity(embedding, query_vector) AS score
FROM products
ORDER BY score DESC
LIMIT 10;

-- Results:
-- 0.92  "Trail Runner Pro - all-day comfort"
-- 0.89  "Cushioned Walking Shoe - arch support"
-- 0.87  "Marathon Training Flat - lightweight"
-- 0.84  "Steel-toe Work Boot - padded insole"  ← relevant?
-- 0.81  "Ballet Flat - memory foam"             ← relevant?
-- No threshold tells you where "relevant" ends
