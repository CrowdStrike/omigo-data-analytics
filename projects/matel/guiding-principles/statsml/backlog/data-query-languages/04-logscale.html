5. LogScale (Humio)

Real-time log search at scale with streaming aggregation
Ingest everything, query anything, in real time. Schema-on-read with streaming aggregation — no pre-indexing needed. The bet: brute-force search on compressed data beats maintaining indexes.
What It Is A log management and observability platform (formerly Humio, acquired by CrowdStrike) that uses index-free streaming search over compressed data for real-time analysis.
Core Idea Streaming search without pre-built indexes. Data is compressed and stored efficiently. Queries scan compressed data in real time. Aggregation happens as events stream through — no batch step required.
Strengths Real-time streaming results (sub-second on recent data). Handles extremely high ingest rates. No schema management or index tuning. Low storage cost via aggressive compression. Live tail of events as they arrive.
Weaknesses Smaller ecosystem than Splunk or Elastic. CrowdStrike acquisition shifts roadmap toward security use cases. Less mature enrichment and correlation capabilities. Community resources are limited. Historical queries on cold data can be slower.
Business Use Case Security log analysis at scale, observability for high-throughput systems, real-time alerting on streaming data, high-volume event correlation in SOC environments.
Example 
#type=accesslog
| status >= 500
| groupBy(field=[url, method], function=count())
| count > 50
| sort(count, order=desc)
