BACKLOG

Handling Skewed Classes

End-to-end framework for working with imbalanced class distributions — from generating realistic skewed datasets to choosing metrics that don't lie.

Goal

Define a principled workflow for skewed-class problems that covers synthetic dataset generation with controlled imbalance ratios, sampling strategies (over/under/hybrid), statistical testing under imbalance, and metric selection that exposes real model behavior on the minority class.

Dataset Generation

  • Controlled imbalance ratios — generate datasets at 10:1, 100:1, 1000:1 to study how methods degrade
  • Class overlap — vary separability independently from ratio; imbalance + overlap is the hard case
  • Multimodal minority class — minority class isn't always one cluster; test with fragmented subpopulations
  • Feature noise injection — irrelevant features that dilute signal, especially harmful at high imbalance
  • Temporal drift in class ratio — ratio shifts over time (e.g., fraud rate changing); test stationarity assumptions

Sampling Strategies

  • Random oversampling — baseline; when it works, when it overfits
  • SMOTE and variants — interpolation assumptions, failure modes with high-dimensional or non-convex classes
  • Random undersampling — information loss trade-off, ensemble-based undersampling (EasyEnsemble, BalanceCascade)
  • Hybrid (SMOTE + Tomek / SMOTE + ENN) — cleaning noisy synthetic points
  • Class-weight adjustment — cost-sensitive learning as an alternative to resampling; when to prefer it
  • Threshold tuning — don't resample, adjust decision boundary post-training

Statistical Testing Under Imbalance

  • Stratified cross-validation — maintaining class ratio in every fold; failure of naive k-fold at extreme ratios
  • Significance testing on minority class — small n in minority → wide confidence intervals; how many minority samples before a t-test/bootstrap is meaningful
  • Permutation tests — model performance vs. random label assignment; especially important when accuracy is misleading
  • Calibration under imbalance — predicted probabilities are systematically off; Platt scaling and isotonic regression post-hoc
  • McNemar's test for model comparison — comparing two classifiers on the same imbalanced test set without accuracy illusions

Metrics

  • Why accuracy fails — 99% accuracy at 100:1 imbalance means predicting majority always; the trivial baseline trap
  • Precision-Recall trade-off — PR curve over ROC when negatives dominate; AUC-PR as primary metric
  • F-beta scores — F1 vs. F2 vs. F0.5; choosing beta based on cost of FP vs FN
  • Matthews Correlation Coefficient (MCC) — balanced measure that works even at extreme ratios; when it disagrees with F1
  • Cohen's Kappa — agreement above chance; sensitive to prevalence in ways MCC isn't
  • Cost-sensitive metrics — expected cost = FP×cost_FP + FN×cost_FN; domain-driven metric design
  • Lift and gain charts — operational metrics for ranked predictions (top-k retrieval scenarios)

Key Questions

  • At what imbalance ratio does each sampling method start to fail or introduce artifacts?
  • How do we validate that SMOTE-generated points respect the true data manifold?
  • When is resampling genuinely better than cost-sensitive learning + threshold tuning?
  • What's the minimum minority-class sample size for reliable metric estimation (bootstrap CI width)?
  • How should train-time imbalance handling interact with test-time evaluation (never resample the test set — but what about validation)?
