Network Security Pitfalls

Why network detection is blind to encrypted payloads, internal lateral movement, and protocol-abusing covert channels.

Encrypted Traffic Opacity

Encrypted Traffic Opacity
TLS 1.3: can't inspect payload without MITM proxy. 85%+ of traffic is encrypted. IDS can only see: packet sizes, timing, destinations — metadata not content. Most signature-based rules are blind to encrypted payloads. Detection must rely on traffic analysis patterns rather than deep packet inspection.

East-West Blindspot

East-West Blindspot
Traditional firewalls sit at the perimeter. Once inside: lateral movement between servers is often UNMONITORED. Attacker inside the network moves freely. "Flat network" = one compromised host = access to everything. Internal traffic volumes dwarf perimeter traffic but receive far less security scrutiny.

Protocol Misuse

Protocol Misuse
DNS used for data exfiltration. HTTPS for C2 communication. ICMP for covert channels. All look like "normal" traffic at protocol level. Detection requires understanding BEHAVIOR within legitimate protocols, not just checking that the protocol headers are well-formed.

DNS Tunneling

DNS Tunneling
Encode stolen data as DNS subdomains: abc123.evil.com. Each query = 255 bytes exfiltrated. Millions of queries = gigabytes stolen. DNS is always allowed through firewalls — perfect covert channel. Standard DNS monitoring rarely inspects subdomain entropy or query frequency patterns.

Bandwidth-Constrained Inspection

Bandwidth-Constrained Inspection
Full packet capture at 10Gbps = 4.3TB/hour. Can't store everything. Must sample or filter. Whatever you don't capture is invisible to retrospective investigation. Evidence destroyed by bandwidth economics. Attackers can hide in the gaps between sampled packets.

Infrastructure Changes Break Baselines

Infrastructure Changes Break Baselines
Migrate from on-prem to cloud → all traffic patterns change. New CDN → different packet timing. Model trained on old infra = useless on new. Every infra change = full retrain. Continuous model drift makes anomaly detection unreliable during transitions.
