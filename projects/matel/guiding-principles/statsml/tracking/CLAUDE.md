# Tracking Data Collection Methods

How data about people, places, and things actually gets collected — the mechanisms, who initiates it, what it captures, and how intrusive it really is.

## Page Structure

Each page uses a 2-column layout (`<table class="obj-table">`, 45%/55% split):

**Left column sections:**
1. What is it? — plain-language explanation
2. What does it collect? — bullet list of actual data points
3. Why do they collect it? — stated purpose vs. hidden purpose
4. How much can they see? — level of detail, intrusiveness

**Right column:** Custom creative canvas visualization per section (not the same chart repeated). Each section gets its own unique viz — data flow diagrams, intrusiveness meters, timelines, comparison bars, layered architecture, etc.

## Style Rules

- **No jargon.** Write for a normal person, not an engineer.
- **Use popular words.** Say "Ring doorbell" not "IoT edge device."
- **Short sentences.** Active voice. Direct.
- **Canvas:** 720×240px, devicePixelRatio scaling, project color palette (#1a5276, #27ae60, #e74c3c, #e67e22)
