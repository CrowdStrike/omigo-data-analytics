Experimental Results Without Experimental Rigor

Claiming the Authority of Science — "We Ran Experiments" — While Violating Every Requirement That Makes Experimentation Meaningful

The Pattern
  • The claim: "We ran experiments. Our model achieves 99% accuracy." Presented as empirical science — the team collected data, ran a model, measured results, and published a number.
  • What was actually done: trained a model on a small or curated dataset, evaluated on a convenient test set (often from the same distribution, sometimes hand-picked), computed a percentage, published it as a finding.
  • What was not done: no power analysis to determine required sample size. No confidence interval to bound uncertainty. No proper held-out test set design. No baseline comparison. No description of what the test set represents or excludes.
  • Why it's pseudoscience: the word "experiment" and the precision of "99%" borrow the authority of the scientific method. But an experiment without adequate controls, without uncertainty quantification, and without reproducibility criteria is not science — it is measurement theater. The number is make-believe dressed in the language of empiricism.
What Makes an Experiment Scientific
  • Hypothesis: a falsifiable prediction stated before running the experiment. "Model X will outperform baseline Y by at least Z% on population P."
  • Sample size justification: before collecting data, calculate how much you need to detect the expected effect with specified power (typically 80%) and significance (α = 0.05).
  • Confidence interval: after measurement, bound the uncertainty. "99% accuracy" at n=100 has CI [94.6%, 99.9%] — meaning the true value could be as low as 94.6%. Reporting the point estimate without the interval is presenting a guess as a fact.
  • Reproducibility: describe the dataset, method, and conditions precisely enough that someone else can replicate and potentially falsify the result.
  • Baseline comparison: "99%" relative to what? Random? Previous best? A simple heuristic? Without a baseline, the number has no interpretive context.

If any of these are missing, you have not run a scientific experiment. You have run a computation and called it science.

How Make-Believe Numbers Are Produced
  • Step 1: Collect or curate a dataset. Often small (n=50–200), often convenient (examples the model is likely to handle well), often from the same distribution as training data.
  • Step 2: Run the model. Compute accuracy, precision, F1, or whatever metric sounds most impressive.
  • Step 3: Normalize to percentage. "99% accuracy."
  • Step 4: Publish without CI, without n, without dataset description. Call it "experimental results."
  • Step 5: The audience reads "we experimented and got 99%" and assigns it the credibility of a controlled study. The format — a number from an "experiment" — triggers trust. The missing rigor is invisible to anyone who doesn't ask the right questions.

The number is technically computed. It is not technically wrong. It is scientifically meaningless. A point estimate from an inadequate sample with no uncertainty bound is not a finding. It is a single draw from a distribution you have not characterized.

The Pseudoscience Markers
  • Claims authority of method without following it: "We ran experiments" implies hypothesis, controls, reproducibility. None were present. The word "experiment" does the legitimizing work.
  • Unfalsifiable: without dataset description or methodology, no one can replicate and potentially disprove the claim. It is insulated from scrutiny by omission.
  • Precision without accuracy: "99.2% accuracy" carries 3 significant figures. The CI spans 8 percentage points. The precision of the number exceeds the actual knowledge by an order of magnitude.
  • Resistant to challenge by format: a number from an "experiment" occupies a privileged epistemic position. Challenging it requires asking "what was your sample size?" — a question that socially implies distrust and is rarely asked in professional settings.
Repeated Evaluation on the Same Test Set
  • The practice: evaluate model → tune → re-evaluate on the same test set → tune again → re-evaluate → repeat 50 times. Report the best score. Call each iteration an "experiment."
  • Why it's pseudoscience: each evaluation informed the next round of tuning. The iterations are not independent experiments — they are a hill-climbing optimization on the evaluation data. The test set has become a second training set, silently. The final "99%" reflects overfitting to the test distribution, not generalization to the problem.
  • The statistical violation: a test set is valid exactly once. After the first evaluation informs a decision (tune, change architecture, select features), the subsequent evaluation on the same data is no longer an independent measurement. It is a biased estimate — biased upward, because you kept the changes that improved the score and discarded the ones that didn't.
  • What actually happens: the model makes mistakes. You see which mistakes it made on the test set. You correct those specific mistakes. The next evaluation improves — but only because you fixed the errors this particular dataset exposed. Errors that a different dataset would expose remain unaddressed and invisible. You optimized for one sample of the problem, not the problem itself.
  • The resulting blind spot: the model now handles the failure modes present in this test set. It does NOT handle failure modes absent from it. A different 1,000 samples from the same population would expose a different set of mistakes — ones you never saw and never corrected. The published "99%" reflects coverage of one sample's error surface, not generalization.
  • What should happen instead: hold out a final test set never seen during development. Use a separate validation set for iterative tuning. Report the final test set result exactly once. If it's disappointing — that's the real number. Everything else was optimizing for the specific errors one dataset happened to surface.

The connection to pseudoscience: calling each iteration an "experiment" and the final best number an "experimental result" appropriates scientific language for a process that violated the independence requirement. The corrections were real, but they were corrections to one sample's error surface — presented as corrections to the problem. That gap is where the pseudoscience lives.

Real vs Pseudoscientific Experimental Claims
  • Real: "Model achieves 94.2% ± 1.3% (95% CI) on 12,400 production samples, compared to 89.1% baseline (McNemar p < 0.001). Dataset: Jan–Mar 2026 production traffic, excluding bot traffic."
  • Pseudo: "Our model achieves 99% accuracy on our benchmark."
  • Both are published as "experimental results." One can be verified, replicated, and falsified. The other cannot. One is science. The other is a claim that borrows the appearance of science.
