Java

Write once, run anywhere. Bytecode + JIT + GC. Safety over flexibility.

  • JVM — interpreter + JIT optimises hot paths
  • Garbage collection — no manual memory
  • Strict single-inheritance OOP
  • Platform independence via bytecode
Trade-off: verbose boilerplate and GC pauses in exchange for safety, portability, and decades of backwards compatibility.
JVM GC managed portable verbose GC pauses 
public class BankAccount {
    private double balance;

    public BankAccount(double initial) {
        this.balance = initial;
    }

    public synchronized void deposit(double amount) {
        if (amount <= 0)
            throw new IllegalArgumentException("Positive only");
        this.balance += amount;
    }

    public double getBalance() { return balance; }
}
// No malloc, no free, no pointers.
// GC reclaims when no references remain.
