Pitfall: Ensemble Leakage (Stacking on Same Data)

Meta-model trained on base predictions from same data.

The Problem

You train base models (e.g., logistic regression, random forest, gradient boosting) on the training set, generate predictions on the same training set, and then train a meta-model (stacker) to combine those predictions. The meta-model sees overfitted base predictions and learns to exploit their training-specific errors.

  • Base models train on dataset D and generate predictions P on D
  • Meta-model trains on P (in-sample base predictions) to predict target Y
  • Base predictions contain overfit patterns specific to training data
  • Meta-model learns to combine these overfit patterns, amplifying overfitting
Impact: The meta-model achieves high training accuracy because it learns to correct the base models' overfit errors on training data. These errors do not replicate on new data, so the meta-model's corrections are useless or harmful in production. Validation performance is worse than expected.

Example: Three base models (RF, GBM, LogReg) train on 10k samples. Generate predictions on the same 10k. Train meta-model on these predictions: train AUC = 0.95. But on test data, base models produce different errors, and meta-model's learned weights hurt performance. Test AUC = 0.80 (worse than best base model at 0.83).

Why It Happens

Base models overfit to some degree. In-sample predictions are systematically better than out-of-sample predictions. The meta-model learns weights based on in-sample performance, which does not transfer.

  • Base model A achieves train AUC = 0.88, test AUC = 0.82 — the 0.88 is overfit
  • Meta-model sees base predictions that reflect 0.88 performance (on training data)
  • Meta-model learns to weight base model A heavily because its in-sample predictions look good
  • On test data, base model A delivers 0.82, not 0.88 — meta-model's weights are miscalibrated
Mechanism: The meta-model is a second-level learner. If its input features (base predictions) are contaminated by overfitting, the meta-model overfits to the overfit. It learns to exploit the correlation between base prediction errors and the target on training data, but those correlations vanish on new data.

Example: Random forest overfits on training sample #47 (predicts 0.95, true = 1). GBM underfits #47 (predicts 0.40, true = 1). Meta-model learns: "when RF high and GBM low, predict high." This pattern is noise. On test data, the pattern is absent, and the meta-model misfires.

Detection & Mitigation

Use out-of-fold (cross-validated) predictions for meta-model training. Generate base predictions on held-out data so the meta-model sees realistic out-of-sample performance.

  • Use K-fold cross-validation: train base models on folds 1-4, predict on fold 5 (repeat for all folds)
  • Collect out-of-fold predictions for all training samples — these are unbiased estimates of base model performance
  • Train meta-model on out-of-fold predictions (not in-sample predictions)
  • For test set: train base models on full training set, generate predictions, feed to meta-model
  • Alternatively, use a held-out validation set: train base models on train, generate predictions on validation, train meta-model on validation predictions
Fix: Generate base model predictions using K-fold cross-validation. Each sample's base prediction comes from models that never saw that sample during training. Train the meta-model on these out-of-fold predictions. This ensures the meta-model learns to combine realistic out-of-sample base predictions.

Example: 5-fold CV stacking. Train RF on folds 1-4, predict fold 5 (200 samples). Repeat 5 times to get predictions for all 1000 training samples. Train meta-model on these 1000 out-of-fold predictions. Result: meta-model learns realistic base model weights. Test AUC = 0.84 (improves over best base model at 0.82).
