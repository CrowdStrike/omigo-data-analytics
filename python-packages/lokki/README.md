# omigo-lokki

Part of the [Data Analytics Library for
Python](https://github.com/CrowdStrike/omigo-data-analytics).

This package is a placeholder. It is released to reserve the name and to pin its
dependencies alongside the rest of the suite, but it exposes no public API yet.
Install [`omigo-core`](https://pypi.org/project/omigo-core/) and
[`omigo-ext`](https://pypi.org/project/omigo-ext/) for the functionality that is
available today.

See the [project
README](https://github.com/CrowdStrike/omigo-data-analytics#readme) for
documentation on the suite.
