# omigo-arjun

Cluster plotting utilities for the [Data Analytics Library for
Python](https://github.com/CrowdStrike/omigo-data-analytics), built on top of
[`omigo-hydra`](https://pypi.org/project/omigo-hydra/).

Like hydra, this package is experimental.

## Install

```
pip3 install omigo-arjun --upgrade
```

## Usage

```python
from omigo_arjun import cluster_plot
```

See the [project
README](https://github.com/CrowdStrike/omigo-data-analytics#readme) for full
documentation.
